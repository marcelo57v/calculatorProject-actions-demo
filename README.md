This is just a simple project for the Software Engeeniring course. Along with other contetns learned throughout the semester (like SCRUM, Agile Methods, Use Case Diagrams, etc), we are finishing it with a project focused on dealing with errors and bugs in the code.

The main idea of this project is to experience how errors would appear in a project using github actions, how they should be treated to be caught in the first place and how should another programmer deal with errors that they didn't code directly. 

The project is a simple calculator, with session memory just for the sake of learning how to create verifiable tests for each functionality and how github actions would show any error for another person in the same project.

Running the project:

- .\.venv\Scripts\Activate.ps1

- python main.py

Then, the calculator is up and running. The memory will only hold values while the session is running, so no long memory.
